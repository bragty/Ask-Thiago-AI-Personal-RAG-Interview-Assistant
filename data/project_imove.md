# Project: iMove Clinical Software System

## Overview

Thiago Bragança Carvalho worked on iMove at the Lake Lucerne Institute.

iMove is a clinical software system for assessing upper-extremity movement quality in stroke rehabilitation.

The project is relevant to Thiago's AI Engineering and Healthcare IT profile because it combines software development, clinical workflows, video handling, user interface development, and system integration.

---

## Project Context

The iMove application supports movement assessment in a neurorehabilitation context.

The system uses video and related data workflows to support the assessment of motor function and movement quality.

The project required software that could function reliably in a clinical or healthcare research setting.
