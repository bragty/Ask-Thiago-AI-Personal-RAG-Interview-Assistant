## DXC ICD-10 Recommender Validation

Thiago contributed to the validation of a RAG-based ICD-10 recommender system.

The system generated ICD-10 code suggestions, which were compared against SAP-coded reference diagnoses.

### Responsibilities

Thiago's responsibilities included:

- Loading and preprocessing SAP and DXC data
- Comparing model-generated ICD-10 predictions with reference ICD-10 codes
- Evaluating main diagnoses
- Evaluating secondary diagnoses
- Working with ICD-10 hierarchy structures
- Applying exact-match metrics
- Applying similarity-based metrics
- Calculating Top-k performance
- Creating chapter-level benchmark analyses
- Supporting result interpretation

### Important Results

Main diagnosis validation results included:

- Top-1 exact match: 21.96%
- Top-5 exact match: 45.57%
- Hit-rate: 49.13%

### Methods Used

The project involved:

- Python
- pandas
- ICD-10 code normalization
- ICD hierarchy analysis
- Top-k evaluation
- Wu-Palmer similarity
- Precision, recall, and F1-score
- Macro and micro metric aggregation
- Excel-based reporting
- Chapter-level benchmarking

---

## Secondary Diagnosis Evaluation

For secondary diagnoses, the evaluation was treated as a multi-label problem.

This means each case could have multiple true ICD-10 codes and multiple predicted ICD-10 codes.

### Evaluation Metrics

The secondary diagnosis evaluation included:

- Recall
- Precision
- F1-score
- Macro aggregation
- Micro aggregation
- Chapter-level hit-rate

### Why It Matters

This is important because real clinical coding often involves multiple diagnoses per case. Evaluating such predictions requires more than simple accuracy.
