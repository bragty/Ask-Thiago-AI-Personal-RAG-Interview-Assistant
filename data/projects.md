## DXC ICD-10 Recommender Validation

Thiago contributed to the validation of a RAG-based ICD-10 recommender system at Kantonsspital Aarau.

The system generated ICD-10 diagnosis code suggestions, which were compared against SAP-coded reference diagnoses.

### Key Points

- Healthcare AI validation project
- RAG-based ICD-10 recommender system
- SAP reference data compared with DXC predictions
- Main diagnosis and secondary diagnosis evaluation
- Python-based validation workflow
- ICD-10 hierarchy analysis
- Top-k evaluation
- Wu-Palmer similarity
- Precision, recall, and F1-score
- Chapter-level benchmarking

### Important Results

- Top-1 exact match for main diagnoses: 21.96%
- Top-5 exact match for main diagnoses: 45.57%
- Main diagnosis hit-rate: 49.13%

### Relevance

This is one of Thiago's strongest Healthcare AI projects because it involved real clinical coding data, model validation, and measurable AI performance evaluation in a hospital context.
