# Projects

## Ask Thiago AI

A personal RAG-based interview chatbot that answers recruiter and hiring-manager questions about Thiago's background, projects, skills, and experience.

The goal is to demonstrate practical AI engineering skills, prompt design, retrieval-based question answering, and professional self-presentation.

## DXC ICD-10 Validation

Thiago validated a RAG-based ICD-10 recommender system at Kantonsspital Aarau. The system generated ICD-10 diagnosis suggestions, which were compared against SAP reference codings.

The project included data preprocessing, matching predictions with reference diagnoses, calculating exact match rates, top-k metrics, Wu-Palmer similarity, and chapter-level performance analysis.

## iMove

iMove is a clinical software system developed at the Lake Lucerne Institute for the assessment of motor function in stroke rehabilitation. Thiago worked on camera preview performance, video recording, UDP communication, SFTP transfer, and UI improvements.
